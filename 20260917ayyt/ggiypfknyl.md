# 【禁忌】越吃越伤胃！5种食物，再饿也别空腹吃！

> 更新时间：2026-09-17 (UTC+8)

**导 读 **DAODU
俗话说“十人九胃”，现在好多人都多多少少有点胃病。

都说疾病是吃出来的，饮食和胃的关系更密切，很多胃部不适都和不良的饮食习惯有关，尤其是在空腹状态下，某些食物要慎吃。

**空腹时，这些食物要少吃****0****1**
**1.红薯**
烤红薯含糖量高，空腹吃会产生大量胃酸，当胃酸过多时会刺激胃黏膜而引起返酸，让人有烧心的感觉。

红薯还含一种氧化酶，在胃肠道里会产生大量二氧化碳气体，容易引起胃胀、打嗝等症状，有胃溃疡、胃胀等病症的人尤其要注意。

**2.柿子、香蕉、柠檬、山楂、荔枝和梨等水果**
《医心方》引《食经》云：空腹勿食生果，喜令人膈上热，为骨蒸，作痈疖。

这句话指出空腹食水果，有可能得膈上热，表现为上焦热，或为骨蒸潮热、痈疖等。

**3.茶**
《古今医统大全》称：“切忌空心茶。”从中医四气角度看，茶性偏寒凉，过量服用可损伤脾阳致食欲不振、腹痛等症状。

**4.酒**
如果人在空腹饥饿时饮酒，乙醇会很快吸收到血液里，可刺激胰腺β-细胞分泌出大量胰岛素，使血糖浓度降低。

即使非空腹状态，也最好不要喝酒。如果一定要喝，每日酒精摄入不宜超过25克，可事前食用富含淀粉或蛋白质的食物，比如米饭、豆腐等，以尽量保护胃粘膜。

**5.糖**

空腹吃糖，糖会改变蛋白质的分子结构，使其成为一种聚糖物质，这种聚糖物质有碍于身体对蛋白质的吸收和利用，使蛋白质的营养价值大为降低，导致营养不良，尤其影响小孩儿的发育。

空腹吃糖，糖可以不经过消化就能被人体立即全部吸收，直接进入血液，从而使人体血糖水平明显升高，加重胰腺负担，进而损害器官功能。

空腹吃糖，糖在体内可转变为磷酸丙糖，在肝内合成低密度脂蛋白，使血中甘油三酯等脂肪物质增多，从而使血流减慢及血黏度增加，微血管中红细胞和血小板更能发生聚集和阻塞，重者可导致心、脑、肝及肾对氧的利用减少而造成器质性病变。

**空腹时不宜做这件事****02**
//
**1.不能多言、忌大怒**

如《折肱漫录》言：“空腹莫多言，最能伤气。”《脉义简摩》记载：“饥后大怒，则必气脱。”

这提示我们空腹不能多言耗气，同时忌大怒，应保持心境平和。

//
**2.进食要缓**

《普济方》中有“修真秘诀云：饥食过多，则结积聚”的记载。

处于饥饿状态，进食要缓慢，不能过多，不然有可能使食物不能消化，导致积聚之疾病。

//
**3.早上忌空腹**

《饮膳正要》提及“古人有云：入广者，朝不可虚，暮不可实。然不独广，凡早皆忌空腹”，说明早上忌空腹，饥饿失时可致脾胃失调，从而导致一系列胃肠疾病。

减肥节食使水谷精微摄入减少，导致气血化生乏源，如女性则使血海空虚，或有月经量减少或闭经等问题，因此应保持均衡饮食。

//
**4.忌洗澡、忌生冷**

空腹也不宜洗澡、剧烈运动和饮食生冷等，均会导致不良反应。

**了解这些空腹饮食的禁忌，养成良好的饮食习惯，避免在不适当的时候食用这些食物，以免给身体带来不必要的损害。**
